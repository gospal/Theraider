How to read this: each timeframe's confluence score weighs seven inputs into one 0–100 read — trend alignment (EMA20/50/200 stack + swing structure), proximity to a key Fibonacci retracement, a detected candlestick pattern, RSI positioning, MACD histogram direction, Bollinger Band position, and volume confirmation.

Overall Bias: the card above combines all three timeframes into one weighted read (1D counts most, 15m least) plus a vote count — it's context for reading the panels, not a replacement for checking each one individually.

Strong Confluence alert: appears when 2 or more of the 3 timeframes agree on direction. It's flagging multi-timeframe agreement, not telling you to enter — still check each panel's setup first.

Stop-loss logic: placed beyond the nearest structural swing point, padded by 1.5× ATR(14), so it sits outside normal noise rather than at a round number.

Trade Setup: Entry is the last close; Target 1/2 are 1.5R and 3R (R = distance to stop), pulled in to the nearest structural level when one sits closer. Shown only when a timeframe has a qualifying long/short signal.

Position Sizing: uses the Account Size and Risk % you set above. Position size is set so that if price hits your stop, the loss equals exactly that % of your account — leverage is then back-solved from that, capped at 25× for display.

Speculative Projection: a straight-line extrapolation of the last 20 candles' closing prices, projected 5 candles forward, with a range band from recent volatility (ATR). This describes where the recent trend points if it continued unchanged — it is not a forecast, and markets regularly deviate from straight lines.

Performance journal: logging a trade saves it in this browser only, not to a server or account. Mark it won, lost, or closed yourself as it plays out, and the stats above the list update automatically.

On leverage: this tool does not tell you to use leverage. It shows a sizing heuristic so that, if you choose to use leverage, your stop-loss risk stays a consistent % of your account regardless of how tight or wide the stop is.

Data from Binance public market data. This is a technical-analysis and sizing tool, not financial advice — indicators and projections describe the past, not guarantee the future. Leveraged positions can be liquidated for a fraction of the loss an unleveraged position would take.
